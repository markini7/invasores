# Mazmorra de Dados: ideas pendientes

## Dados con más variedad

**Hecho en v0.37 solo para los dados especiales** (ver ESTADO.md). Ataque y Protección siguen iguales para todos; lo de abajo queda como idea para cuando se cambien también.

Problema: si un dado solo puede sacar "1 de daño", volver a tirarlo no tiene gracia. La idea es que cada dado tenga caras de tipos distintos y una o dos vacías, para que siempre haya algo que arriesgar.

### Caras nuevas propuestas

- **Aturdir X**: si el ataque de ese enemigo es de X o menos, ese turno no ataca.
- **Debilitar X**: ese enemigo pega X menos este turno.
- **Marcar X**: ese enemigo recibe +X de cada golpe este turno.
- **Esquivar X**: el primer golpe de X o menos que te den no te hace daño.
- **Robar X**: le quitas X de protección y ganas X de oro.
- **Rapidez**: +1 re-tirada (si te sale, sigues tirando).
- **Drenar X**: le quitas X de vida y te curas X.
- **Bendición X**: te curas X y ganas X de protección.
- **Vendaje X**: te curas X.
